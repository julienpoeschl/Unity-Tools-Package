# Personal Unity Editor Tools Package
A [Unity](https://unity.com) 6 package, created using my [Unity-Package-Template](https://github.com/julienpoeschl/Unity-Package-Template), containing additional unity editor tools such as custom script creation via templates and quick access to settings.

For more details, read the [documentation](com.julienpoeschl.tools/Documentation/index.md) or [changelog](com.julienpoeschl.tools/CHANGELOG.md).
